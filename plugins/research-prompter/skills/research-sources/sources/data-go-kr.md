# 공공데이터포털 (data.go.kr)

조달·입찰·건설업체·건설공사 관련 API가 다수 등록돼 있다.
**인증키 1개로 여러 서비스를 신청해 쓴다.**

발급: https://www.data.go.kr

## 주요 활용

| API 계열 | 용도 |
|---|---|
| 나라장터 입찰공고·낙찰 정보 | 발주 동향 **정량** 분석 |
| 건설공사·건설업 등록 정보 | 시장 구조 파악 |
| 한국연구재단_KCI 논문정보 | `sources/kci.md` 대안 경로 |

## 함정 (여기서 대부분 막힌다)

- **파라미터명을 추정하지 말 것.** 서비스마다 다르다.
  **첫 사용 전 해당 API 상세페이지에서 요청 파라미터와 트래픽 한도를 반드시 확인한다.**
- **`ServiceKey`는 URL 인코딩이 필요한 경우가 많다.** 포털이 주는 "인코딩 키"와
  "디코딩 키"가 따로 있다. 둘을 바꿔 쓰면 인증 실패가 **빈 결과처럼** 보인다.
- 응답 포맷이 서비스마다 JSON/XML로 갈린다. `_type=json` 파라미터를 지원하는지 확인한다.
- 개발계정은 트래픽 한도가 있다(흔히 일 1,000~5,000건).
  운영계정은 활용사례 등록 후 증액 신청.
- **에러가 HTTP 200 + 에러코드 본문으로 온다.** 응답 본문의 `resultCode`를 확인하지 않으면
  실패를 "자료 없음"으로 오인한다.

```bash
# 호출 후 반드시 결과 코드부터 확인한다
curl -s "https://apis.data.go.kr/<서비스경로>?ServiceKey=${DATA_GO_KR_KEY}&_type=json&pageNo=1&numOfRows=100" \
  | jq '.response.header'
```
