# 도메인 프로토콜 — 국내 학술논문

> 적용 대상: 국내 학술지 논문, 학위논문, 국가 R&D 보고서를 근거로 삼는 모든 리서치.
> 공통 절대 규칙(조용한 실패 감지, 서지 확정, polite pool)은 상위 `SKILL.md` §2를 먼저 읽는다.
> 이 파일은 **이 도메인 고유의 것**만 담는다: 예산, 순서, 등급, 도메인 전용 함정.

---

## 0. 이 도메인의 절대 규칙

1. **DOI 또는 KCI 논문ID(`artiId`)가 없는 국내 논문은 인용하지 않는다.**
   확보 못 하면 해당 주장을 보고서에서 **삭제한다.** 약화가 아니라 삭제다.
2. **해외 색인에서 안 나온다고 논문이 없는 것이 아니다.** 국내 학술지는 OpenAlex
   커버리지가 얕다. KCI 결과가 우선이고, 해외 색인은 교차검증용이다.
3. **한국어 제목 논문은 해외 색인에서 영문 제목으로만 잡힌다.** 국문 검색어로 Crossref를
   때리면 0건이 나온다. KCI에서 영문 제목을 먼저 확보한 뒤 교차확인한다.
4. **출처표시 의무.** KCI 데이터는 공공누리 "출처표시" 조건이다. RAG 방식으로 직접 인용
   시 출처 명시가 의무. 보고서에 `출처: 한국학술지인용색인(KCI)`를 넣는다.
   ScienceON 자료 인용 시에는 `출처: 한국과학기술정보연구원(KISTI)`를 표기한다.

## 1. 검색 예산 배분

WebSearch 호출 한도는 **메인 대화와 모든 서브에이전트가 공유**한다. 병렬 팬아웃이 각자
자유롭게 쓰면 먼저 도는 에이전트가 전부 소진한다.

| 용도 | 도구 | 예산 |
|---|---|---|
| 초기 스코핑 (핵심 용어·주요 연구자 파악) | WebSearch | 에이전트당 **최대 10회** |
| 논문 검색·서지 수집 | KCI / ScienceON API | **무제한** |
| 해외 색인 교차확인 | Crossref / OpenAlex / S2 | **무제한** |
| 논문 상세페이지·PDF 본문 확인 | WebFetch | **무제한** |
| RISS·DBpia 등 API 없는 DB | WebFetch (수동, 1건씩) | 필요 시 |

**원칙: WebSearch는 "무엇을 찾아야 하는지 모를 때"만 쓴다.
찾을 대상이 정해진 순간부터는 API로 전환한다.**

## 2. 수집 순서

```
1. 스코핑: WebSearch ≤10회로 핵심 용어·주요 연구자 파악
2. 수집:   sources/kci.md      → 국내 논문 후보군 (국문·영문 제목 모두 기록)
3. 확장:   sources/scienceon.md → 프로시딩·국가R&D보고서 보완 (KCI에 없는 40만 건)
4. 검증:   sources/crossref.md  → 확보한 DOI 재조회, 서지 확정
5. 추적:   sources/openalex.md  → cites 필터로 후속 연구·인용 네트워크 확장
6. 정독:   sources/semantic-scholar.md → OA PDF 링크 확보 → WebFetch 본문
           (본문 없으면 "초록 기반" 명시)
7. 정리:   출처 등급 태깅 + 공공누리 출처표시 삽입
```

2→3 순서가 중요하다. KCI는 **등재지**가 기준이라 학회 프로시딩·보고서가 빠진다.
ScienceON을 건너뛰면 그 영역이 통째로 누락된다.

---

## 3. RISS · DBpia — 함정

- **공개 OpenAPI가 없다.** 프로그램적 대량 수집 경로가 존재하지 않는다.
- 로그인·기관인증 벽에 막히는 경우가 많고, 대부분 서지 메타데이터만 노출된다.
- RISS는 **학위논문 탐색**에 유용하다. 발견(discovery)은 WebSearch로 하되
  (`site:riss.kr 모듈러 건축 생산성 학위논문`), **서지 확정은 KCI/ScienceON으로 되돌아온다.**
- 자동 크롤링 금지 (상위 `SKILL.md` §2-5).

## 4. 출처 등급

| 등급 | 정의 | 필수 메타데이터 |
|---|---|---|
| **A** | KCI 등재·등재후보 학술지 논문 | 저자, 제목, 학술지명, 권(호), 연도, 페이지, DOI 또는 KCI `artiId` |
| **B** | 국가 R&D 보고서, 정부·출연연 공식 보고서 | 발행기관, 보고서명, 발행연도, 보고서번호, URL |
| **C** | 학위논문 | 저자, 논문명, 학위종류, 수여기관, 연도 |
| **D** | 학회 발표자료, 프로시딩 | 저자, 제목, 학술대회명, 개최연도 |

- 모든 주장에 등급을 태깅한다. 예: `모듈러 공법의 공기 단축 효과는 평균 20~30%로 보고된다 [A]`
- **A~D 어디에도 해당하지 않는 출처는 이 프로토콜의 산출물에 들어갈 수 없다.**
  블로그·언론기사·벤더 자료는 `domains/epc.md`의 관할이다. 두 도메인을 함께 부착한
  리서치라면 그쪽 등급(T1~T5)으로 넘긴다.
